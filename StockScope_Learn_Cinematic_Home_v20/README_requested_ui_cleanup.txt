StockScope Learn 本次界面清理说明

本版本基于上一版技术指标教学精简包更新。

修改内容
1. 删除所有教学单元顶部的「学看练复盘」四阶段卡片，不影响课程正文、互动图表和知识测验。
2. 删除所有通用「用自己的话复盘」文本框。为保留学习进度统计，原位置改为简单的「标记本课完成」按钮，不再要求输入复盘文字。
3. 将各教学单元的参考资料、延伸阅读区和散落的教学参考链接移除；数据来源、方法说明和官方学习资料集中保留在「数据与方法」页面。
4. 删除所有课程横幅中的「真实历史数据」「一步一步学习」「图表互动 + 小测验」三个重复标签。
5. 左侧主菜单当前选中项改为绿色背景，并强制覆盖 Streamlit 默认红色 radio accent，选中圆点使用绿色。
6. 清理过时的复盘进度描述；学习完成状态仍可手动标记，知识检查进度仍照常统计。

验证
- Python 编译/语法检查通过。
- 确认旧的 render_learning_cycle、finish_lesson_button、反思文本框与 hero pills 代码已移除。
- 确认教学单元的参考/延伸阅读区已移除，相关资料保留在「数据与方法」页面。
- 当前执行环境没有安装 Streamlit，因此未能在该环境启动完整应用进行端到端浏览器验收。

使用方法
将 ZIP 内文件解压并覆盖到原 StockScope Learn 项目文件夹，再运行 start_windows.bat。
