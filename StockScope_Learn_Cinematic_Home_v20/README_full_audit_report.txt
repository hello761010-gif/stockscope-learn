本包内容
- app.py：更新后的完整 Streamlit 应用
- requirements.txt：运行依赖
- start_windows.bat：Windows 一键启动脚本

本轮重点修正
1. 第二课「看懂行情」
   - 「每日成交量」说明文字移到 Plotly 图表外部。
   - 成交量图取消图内标题，使用独立小标题与说明文字。
   - 图表保留独立上边距，减少说明文字与绘图区挤在一起的风险。
2. 图表标题与标签
   - K 线、真实历史 K 线、形态示意图与三张财报图表统一将标题放在 Streamlit 内容流中，不再让图内标题与上方文字争抢空间。
   - 技术指标图为可能换行的多项目图例预留更大的上方区域。
   - 损益表横轴标签轻微倾斜并增加底部空间，降低窄屏下文字拥挤。
   - 资产负债表和现金流图增加轴标签自动留白及右侧金额标签空间。
3. 页面适配
   - 保留窄屏下栏目堆叠及 Plotly 宽度自适应设置。
   - 修正首页重复表达的一句文案。
4. 启动环境
   - requirements.txt 明确要求 Streamlit 1.66.0 或更新版本。
   - Windows 启动脚本会检查 Python 版本、依赖是否齐全及所需 Streamlit API；缺少或版本不足时才执行安装。

检查边界与注意事项
本环境没有安装 Streamlit 和 yfinance，因此无法在这里启动真正的 Streamlit 服务，也无法调用实时 Yahoo Finance 数据源。浏览器本地访问受到运行环境限制，故本轮无法完成真实浏览器的像素级截图检查。页面分支、图表对象和交互流程使用模拟 Streamlit 与模拟行情数据测试；这能发现大量 Python 逻辑错误，但不能证明所有电脑、浏览器和手机宽度下都绝对没有视觉错位。

建议在本机解压后双击 start_windows.bat，依次检查「02 看懂行情」「02B 技术指标入门」「04 研究一家公司」的桌面和窄屏显示。若实时数据暂时不可用，页面应显示数据提示，而不是直接崩溃。
