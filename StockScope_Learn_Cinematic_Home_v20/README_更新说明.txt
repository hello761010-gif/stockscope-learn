StockScope Learn｜UI 与指标点击学习版

安装/更新：
1. 将本压缩包解压到现有 StockScope Learn 项目文件夹。
2. 覆盖 app.py 和 start_windows.bat（也可保留你自己维护的启动脚本）。
3. 保留 requirements.txt，并双击 start_windows.bat 启动。

本次更新：
- 修复下拉选项、焦点、悬停与选中状态变成白底导致的文字对比度问题；菜单保持深色，选中态使用蓝绿强调色。
- 在左侧主菜单增加“收起主菜单”按钮；收起后左上角提供固定的“展开主菜单”按钮。
- 技术指标实验室改为图表与学习卡并排显示。可点击 K 线、指标线、支撑/阻力参考线、斐波那契回撤线及图例，学习卡会显示该线的用途、读法、常见误区，并在可用时显示日期和值。
- 为指标线增加低密度的小节点，增加可点击感；手机窄屏下图表与学习卡纵向排布。
- 参考水平线和支撑/阻力、斐波那契线改为可交互数据线，不再只是静态 shape。

验证：
- app.py 已通过 Python 语法编译。
- 基于合成 OHLCV 行情测试了 RSI、MACD、Stochastic、ADX、OBV 与纯 K 线模式，以及高低位/斐波那契叠加。
- 生成的图表 HTML 内联 JavaScript 已通过 Node.js 语法检查。
- 当前执行环境没有安装 Streamlit，未能进行真实浏览器中的完整交互验收。

提示：可点击交互图表使用浏览器加载与本地 Plotly Python 包相匹配的 Plotly.js CDN 资源，因此浏览器需要能够访问 cdn.plot.ly；行情数据仍通过 yfinance 获取。
