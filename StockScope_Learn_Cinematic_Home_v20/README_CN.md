# StockScope Learn V20

## 本版更新（首页情景 01）
- 提升图表图例的可读性：深色图例底、浅色边框、白色文字、较大的字号；MA5／MA20、DIF／DEA 使用更鲜明的线条颜色。
- 明确显示颜色规则：K 线及成交量「绿涨红跌」；MACD 柱的绿／红表示柱体正值／负值，不等同于股价的涨跌方向。
- 历史数据窗口截止到 **2026-10-06**，不会把此日期之后的数据放进本情景。
- 答题前只显示截至观察日的真实历史行情；选择题放在图表右侧空白区域，题干不提示均线或 MACD 交叉事件，也不显示交叉日期或标记。
- 提交答案后，题目与选项消失；图表扩展为全宽，未来 20 个交易日的真实 K 线、MA、成交量和 MACD 直接接到原有走势右侧。
- 答案揭晓后才在图中突出标记 MA5 上穿 MA20 与 DIF 上穿 DEA 的日期，并在图下解释其含义及指标滞后、假信号等限制。
- 保留此前 V18 的进阶综合测验和答题结果红绿高亮，以及其余两道首页情景挑战。

## Windows 启动
1. 解压 `StockScope_V20.zip` 到一个完整文件夹。
2. 如有需要，安装 `requirements.txt` 中的依赖。
3. 双击 `start_windows.bat` 启动 Streamlit。

## 数据与限制
情景 01 的历史 K 线来自 Yahoo Finance / yfinance 获取的真实调整后日线。应用会在运行时筛选截至 2026-10-06 且具有完整后续 20 个交易日的历史样本；如果行情服务不可用或找不到符合条件的样本，页面会提示无法加载，不会使用合成价格替代。作者环境已完成 Python 语法与图表状态的静态／合成数据测试，但没有可用的 Streamlit 与 yfinance 运行环境进行实时行情和浏览器端到端测试。
