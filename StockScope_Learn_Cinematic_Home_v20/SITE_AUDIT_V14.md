# StockScope Learn V14 — 页面与动效检查记录

## 修改内容

1. 首页第一章节（`#cinematic-signal`）的标题已拆成两个可单独动画的短语。
2. 第一短语「先看见变化，」从左侧进入。
3. 第二短语「再理解变化。」延迟约 0.2 秒后从左侧进入，并使用原有的浅蓝色强调色。
4. 标题后的细线从左至右展开，延迟约 0.43 秒开始。
5. 标题使用独立的 `data-title-reveal` 观察属性，不再把标题动画绑定到正文整块容器；正文和章节标签仍独立沿原有方向浮现。
6. 修改 IntersectionObserver 选择器，使其同时观察 `[data-reveal]` 和 `[data-title-reveal]`。
7. 不修改视频轮播与播放控制：保持 7 段视频、Coverr 末段、直接硬切、约 3 秒片段节奏以及 1.3× 速率；没有加入视频透明度过渡。
