StockScope Learn｜技术指标模块 Bug 修复版

使用方法：
1. 将本压缩包解压到 StockScope Learn 项目文件夹。
2. 覆盖 app.py、start_windows.bat，并保留/核对 requirements.txt。
3. 双击 start_windows.bat 启动。

本次修复与检查：
- 斐波那契回撤改为按页面所选的完整历史范围（3 个月、6 个月、1 年、5 年）使用最高价、最低价计算，不再固定只看最近 60 个交易日。
- 高低位参考线同步使用所选完整历史范围，并标注为“区间高位/低位参考”。
- 页面会显示当前范围的起止日期、最高/最低价及对应日期，避免误以为线位只覆盖最近数月。
- 如果区间最高点和最低点在同一根 K 线上，程序不猜测波段方向，也不绘制斐波那契线。
- 指标先基于更长的 10 年历史进行计算，再截取所选显示范围，降低切换 3 个月/1 年等范围时 RSI、EMA、MACD、ADX 等指标因初始化历史不同而变动的问题。
- OBV 在可见区间内重新设定相对起点，避免较长历史的累计基数压扁短期变化。
- 检查了 RSI / 随机指标数值范围、各副图模式、主图无副图模式，以及 3 个月、6 个月、1 年、5 年的完整区间线位。

验证说明：
- 已通过 Python 语法检查和基于合成 OHLCV 行情的指标/图表测试。
- 当前执行环境没有安装 Streamlit 与 yfinance，无法在此处启动整个网页并进行联网行情的浏览器端验收。
